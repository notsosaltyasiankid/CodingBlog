## What is Astro?

Astro is a web framework made to build fast, content-focused websites. It focuses on delivering HTML to the browser while only loading JavaScript when it is needed for interactive components. Astro renders components into HTML by default. When a component needs interactivity, JavaScript can be added to the page. This helps keep websites lightweight while still allowing developers to create interactive experiences.

You could even use JavaScript UI components, CSS libraries, themes, and integrations into your own project so the customization is endless! One of Astro's most interesting features is its Island Architecture. This allows developers to build a page mostly with static HTML while adding interactive components, or "islands," wherever they are needed. For example, a blog could have a static article with an interactive comment section. Only the interactive part needs to load JavaScript, helping keep the website fast. 

But what should you use it for? Well, most people use it for blogs, portfolios, landing pages, documentation, and more. With all these benefits, I thought it would be fun to give Astro a try. Maybe you should too!

## Why I Started Working with Astro

It began with my starting position as a software developer intern at VPRO. Most of the projects
were run with the framework, and I needed to adapt to that way of working. I read the documentation of Astro that they provided and started my own test project. With my beginner-level knowledge of web development I only tested the island architecture and how it worked. My skills with HTML/CSS and JavaScript were also not the best, so I thought it would be the best if I could try and learn as much as possible with Astro whilst also learning more and more coding languages.
